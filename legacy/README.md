# Versão estática original (sem build)

Blog em React via CDN (UMD) + Babel no navegador.

## Como rodar

Na pasta `legacy/`:

```bash
npx --yes serve .
```

Abra a URL indicada no terminal (por exemplo `http://localhost:3000`) e use a página `index.html`.

Alternativa: `python3 -m http.server 8080` e acesse `http://localhost:8080/index.html`.

Não é necessário `npm install` para esta versão.
